# Country Travel Snapshot

A Python command-line tool that uses the REST Countries API to generate a travel snapshot for a country.

## Features

The tool displays:

- Country name
- Capital
- Currency
- Population
- Languages
- Region
- Neighbouring countries

It also handles invalid countries, missing data, API errors, network errors, and unexpected responses.

## Technologies Used

- Python
- Requests
- REST Countries API
- JSON
- Git & GitHub
